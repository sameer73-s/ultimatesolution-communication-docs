# Ultimate Solution Communication — Living Documentation

هذا المستودع هو المرجع الحي لمشروع منصة التواصل المؤسسي. يحتفظ بالدليل المعماري والبرومبت الرئيسي وقرارات التصميم ADRs ومخرجات المرحلة 1 القابلة للتحرير والمراجعة.

| المسار | المحتوى |
|---|---|
| `reference/` | الدليل المعماري والبرومبت الرئيسي المعتمدان. |
| `adr/` | سجلات القرارات المعمارية، ومنها ADR-001 وADR-002. |
| `system-design/` | ERD، المعمارية، مخططات التسلسل، نموذج البيانات، وعقد API الأولي. |

أي تغيير معتمد في Architecture Guideline أو قرار معماري أو عقد API يحدّث هنا أولًا، ثم يشار إليه من مستودعي Backend وMobile. تتبع المساهمة سياسة الفروع وطلبات السحب في [CONTRIBUTING.md](CONTRIBUTING.md).
